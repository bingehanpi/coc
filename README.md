# coc
联赛排名

1.在release目录下下载cwl.zip解压后运行CWL分析工具.exe

2.点击"获取Api token"按钮,登录https://developer.clashofclans.com/ ,自行创建账号和设立官方api,最好不要使用科学上网(看不懂这句话不影响),这里提供ip查询:

3.自行查找本地ip并完成官方api的创建

4.在API_TOKEN后面填入你的apikey,点击"开始查询"按钮

5.根据结果(如果会报错)在错误提示中找到你的在网ip地址,根据这个ip地址重新创建api

6.再次点击"开始查询"按钮,正常情况可以获得运行结果了
